# Security Policy

## Supported Versions

| Version | Supported |
|---------|:---------:|
| 0.3.x   | Yes       |
| < 0.3.0 | No        |

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability, please report it
through coordinated disclosure rather than the public issue tracker.

**Email:** [security@example.com](mailto:security@example.com)

Please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Your name and affiliation (optional)

## Response Timeline

We aim to respond within 48 hours and provide a fix within 90 days.

## Disclosure Policy

We follow a coordinated disclosure policy with a 90-day window:

- Day 0: Vulnerability reported
- Day 1-7: Initial assessment and reproduction
- Day 8-80: Fix development and testing
- Day 81-90: Coordinated public disclosure

## Scope

This policy applies to the latest supported release of chainsaw.
Third-party dependencies are out of scope but will be triaged if reported.
